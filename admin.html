Review Tool — Admin

One-time setup (10 minutes)

  1. Go to console.firebase.google.com → Add project (any name, e.g. tamil-review). Analytics can stay off.
  2. In the project: Build → Realtime Database → Create database → start in test mode → pick nearest region.
  3. Project settings (gear) → Your apps → Web (</>) → register an app (no hosting needed) → copy the firebaseConfig values into config.js next to this file (replace the PASTE_… placeholders). The databaseURL must be present — it looks like https://<project>-default-rtdb.firebaseio.com.
  4. Database rules (test mode is fine for this study — the data has no names, only codes). If you later edit rules, keep read/write true for paths /items /meta /counts /responses.
  5. Host these three files together online: push the review-tool/ folder to a GitHub repo → Settings → Pages → deploy from branch (or Firebase Hosting). Reviewers get that URL.
  6. Below: import the test cases (and results after your model run finishes), then share index.html's link with reviewers.
